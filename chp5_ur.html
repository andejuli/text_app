Chapter 5

SQL Querying Tools

Learn how SQL functions, joins, and summary queries help turn stored data into clear, useful information for analysis and decision-making.

Why SQL Becomes More Powerful

In the last chapter, we focused on the core syntax of single-table queries. Those basics remain important, but SQL becomes far more useful when we can reshape values, combine related tables, and summarize large sets of rows. For information systems work, these tools are essential because they help turn raw database content into information that people can actually use.

Functions That Shape Data

SQL functions let you work with values before they are displayed or stored. Scalar functions operate on one row at a time, which makes them useful for cleaning text, adjusting numbers, and extracting parts of dates. This is especially helpful when data needs to be standardized for reports or analysis.

Text Functions

Text functions combine or transform strings. They can build readable labels, change letter case, or pull part of a word from a column value.

SELECT CONCAT('The primary key of ', keyword, ' is ', keyword_id) AS new_string
FROM keyword
WHERE keyword_id = 1;

Result

new_string
The primary key of sky is 1
 
SELECT LEFT(keyword, 4) AS left_part, LENGTH(keyword) AS char_count, UPPER(keyword) AS upper_keyword
FROM keyword
WHERE keyword_id = 2;

Result

left_partchar_countupper_keyword
land9LANDSCAPE

Numeric and Date Functions

Numeric functions are useful when values need to be rounded, compared, or formatted for display. Date and time functions help pull out parts of a date, calculate time differences, or present dates in a friendlier format.

SELECT ROUND(magPrice) AS rounded_price, FLOOR(magPrice) AS lower_whole, CEILING(magPrice) AS upper_whole

Joining Related Tables

Relational databases are split into related tables during normalization, so the information often has to be joined back together for reporting. A JOIN combines rows from tables that share a related key. In most cases, that means matching a primary key in one table to a foreign key in another. Using explicit join syntax keeps the relationship clear and readable.

INNER JOIN is the most common join. It returns only rows that have matching values in both tables.

SELECT lastName, firstName, subStartDate
FROM subscriber
    INNER JOIN subscription
        ON subscriber.subKey = subscription.subKey
ORDER BY lastName;

When a query needs data from three related tables, aliases keep the SQL manageable. The example below finds subscribers to a specific magazine by joining the subscriber, subscription, and magazine tables.

SELECT lastName AS Last_Name, firstName AS First_Name
FROM subscriber sr
    JOIN subscription sn
        ON sr.subKey = sn.subKey
    JOIN magazine m
        ON sn.magKey = m.magKey
WHERE magName = 'Beautiful Birds'
ORDER BY Last_Name;

Result

Last_NameFirst_Name
LamontLucy
SandersSamantha

An OUTER JOIN matters when completeness is more important than matching rows alone. A LEFT JOIN keeps every row from the left table even when there is no match on the right, which is useful when missing related data should still be visible.

Summary Queries

When a business question asks for a total, an average, a highest value, or a count, SQL uses aggregate functions. These functions operate on a set of rows and return a single result, which makes them ideal for dashboards, reports, and decision support.

SELECT AVG(salary) AS Average_Salary
FROM salaries;

Result

Average_Salary
64238.8072
 
SELECT COUNT(*) AS Number_of_Employees
FROM employees;

Result

Number_of_Employees
9488

The DISTINCT keyword can reduce duplicate values before an aggregate is calculated. The GROUP BY clause then creates groups so each subset can be summarized separately.

SELECT vendor_id, COUNT(*) AS Number_of_Products
FROM products
GROUP BY vendor_id;

SELECT vendor_id, COUNT(*) AS Number_of_Products
FROM products
GROUP BY vendor_id
HAVING COUNT(*) > 20;

Why This Matters

Functions, joins, and summary queries are some of the most practical tools in SQL. Functions clean and format values, joins reconnect related tables, and aggregates convert rows of data into information that is easier to interpret. For information systems students, these are the skills that make database data useful in real applications.
